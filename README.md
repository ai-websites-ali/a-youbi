# Cabinet A.YOUBI

Site de présentation du Cabinet de comptabilité et commissariat aux comptes A.YOUBI (Réghaïa, Alger).

## Stack

- Next.js App Router
- TypeScript (strict)
- Tailwind CSS
- Déploiement compatible Vercel

## Commandes

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
npm run start
npm run verify
```

`npm run verify` lance une vérification Playwright contre le serveur de production local (`BASE_URL`, défaut `http://127.0.0.1:3005`).

## Contenu

Les informations vérifiées, de démonstration et à confirmer sont centralisées dans `src/config/`.
